Project Brief

SPARKLECHAT とは

商品概要： Twitch 配信用の OBS ブラウザソース型チャットオーバーレイ。 ログイン不要で匿名接続し、チャット・枠・アラートの3種類のオーバーレイを提供する。 BOOTH でのファイル販売を想定して制作中。

販売者

日本語話者のクリエイター。ikiiro56@gmail.com。BOOTHで販売予定のOBSウィジェット。

ユーザー

日本語圏の Twitch 配信者。OBS に URL を貼るだけで使える手軽さが重要。

配信先

GitHub: gugu219/sparkle-chat
Vercel: sparkle-chat-gamma.vercel.app

ビルドなし

plain HTML / CSS / JS のみ。npm run build 不要。Vercel に push すれば即反映。

Overlay 1

Chat Overlay — view.html

  • tmi.js で Twitch チャンネルに匿名接続（ログイン不要）
  • バッジ画像：/api/badges 経由で Twitch Helix から取得（サブスク・VIP・モデレータ等）
  • サブスク / VIP / モデ バッジを グラデーション背景の丸バッジで表示、その他バッジは表示/非表示切替可
  • エモート：Twitch 公式エモートを画像で表示（BTTV 非対応）
  • メッセージマーカー（ハート・星・スパークル）、オプションで光るアニメ
  • チャンネルポイント使用時の強調表示
  • チアー（Bits）通知インライン表示
  • 右寄せ / 左寄せ切り替え
  • 文字サイズ・最大表示件数・改行文字数をスライダーで設定
  • デモモード：ループ再生で架空の日英チャットを流す
  • フォント 15 種類（日本語 10・英語 5）
バグ修正済み： t.badges はオブジェクト型なのに .includes() を呼んでクラッシュしていた（→ hasBadge(t,k) 関数で修正）。is-leaving の要素もカウントして早期削除していた（→ 非leaving要素のみカウントに修正）。
Overlay 2

Frame Overlay — frame.html

  • SVG マスク技術（evenodd fill-rule）で中抜きリング型の枠を生成
  • 外側・内側の角丸を独立して調整（--fr / --fri）
  • パーティクルシステム：rise / fall / float / pile の4モーション
  • pile: 画面下にたまる物理演算（列ごとの高さマップ）
  • イベント別パーティクル設定（形状・動き・数・サイズ・速度・不透明度・カラーモード・4色）
  • 枠の発光（シーン）を ON/OFF する設定
  • カラーパレット保存（Web 上で複数カラーを保持）
  • サブスクギフトのサプレッション（submysterygift→1回のみ、個別 subgift は無視）

Alert Overlay — alert.html

最も新しく、最も多機能。全イベントが独立した音・音量・表示時間を持つ。

イベントアイコン特記事項

アラートデザイン仕様

  • グラスモーフィズム吹き出し（背景色・不透明度・ぼかし・彩度）
  • アニメ種別：poyon / slide / drop / zoom の4種
  • 吹き出しの角丸（0〜999px ピル型まで）
  • ボーダー・グロー（発光）独立設定
  • 表示位置：9箇所（tl/tc/tr/ml/mc/mr/bl/bc/br）
  • タイトル文字の入場アニメ
  • 数字カウントアップ演出（イージング付き）
  • 連続視聴は「190 回」形式（× なし）、時間比例カウント

8-bit チップチューン音

  • Web Audio API による手続き型生成（音声ファイルなし）
  • 登場音・カウント中ビクンッ音・到達ジングル（回数で豪華さ変化）
  • 100/200/300… 回でファンファーレ（grand jingle）
  • ユーザー定義音：ローカルファイル → /api/sound → Redis 保存 → 短縮 ID
  • 最大ファイルサイズ：700KB（base64 で約93万文字）

連続視聴（Watch Streak）検知方法

// 1. 公式 IRC タグ（最も確実）
msg.tags['msg-id'] === 'viewermilestone'
&& msg.tags['msg-param-category'] === 'watch-streak'

// 2. 英語テキスト
/(\S+)\s+watched\s+([\d,]+)\s+consecutive\s+streams/i

// 3. 日本語テキスト（全角数字対応）
/([^\s　！!？?。、,，]+)\s*さんは\s*(?:現在)?\s*[、,]?\s*([0-9０-９,，]+)\s*日?\s*(?:連続視聴|日連続視聴)中/
Settings UI

設定エディタ — index.html + script.js

  • 3タブ（チャット / 枠 / アラート）、コラプシブルセクション
  • persist(form, key, values) 関数で localStorage への自動保存・復元
  • チャンネル名入力で枠・アラートの空フィールドを自動同期（syncChannels()）
  • 「URL に反映」ボタンで URL パラメータを生成・コピー
  • iframe プレビューに postMessage でリアルタイム設定反映（リロードなし）
  • プレビュー背景 5 種（チェッカー / 暗 / 明 / 緑 / カスタム）
  • テストボタン：各イベントをプレビューで確認
  • 音声ライブラリ：ローカルファイルをアップロードして使い回し可
  • デモモード（demo=1 URL パラメータ）：OBS でも架空チャットをループ
Pattern

設定フロー

エディタ（index.html）
  ↓ 入力・スライダー操作
  → localStorage に自動保存
  → iframe に postMessage { type:'sparkle-settings', settings:{…} }
    → オーバーレイ側の window.addEventListener('message') で受信
    → apply() で CSS 変数・クラスを即時更新（リロードなし）

「URL に反映」ボタン
  → URLSearchParams を構築（音声はデータ URI でなく短縮 ID のみ）
  → クリップボードにコピー

OBS ブラウザソース
  → URL パラメータで初期化（localStorage なし）
  → tmi.js で Twitch IRC に匿名接続
重要： 音声データ URI を URL に含めると Vercel で 414 URI_TOO_LONG が発生する。 音声は必ず /api/sound にアップロードし、返却される短縮 ID（22文字）を URL に使うこと。
Pattern

Twitch IRC 接続（匿名）

import tmi from './vendor/tmi.bundle.mjs';
const c = new tmi.Client({ channels: [channel] });
// ↑ username / password なし = 匿名接続

c.on('message', (ch, tags, msg, self) => { … });
c.on('sub', …);
c.on('resub', …);
c.on('submysterygift', …);  // ギフト数まとめ通知
c.on('subgift', …);          // 個別ギフト（サプレッション処理）
c.on('cheer', …);
c.on('raw_message', (_cloned, msg) => {
  // viewermilestone (連続視聴) はここで検知
});

匿名でもバッジ・エモート・ビッツ・サブ・ギフト・チャンネルポイントが全て動作する。 hasBadge(tags, key) でバッジ判定（tags.badges はオブジェクト型）。

Pattern

Vercel API エンドポイント

GET /api/badges?channel=xxx

Twitch Helix からグローバル＋チャンネルバッジを取得。Redis に1時間キャッシュ。戻り値: {"subscriber/6": "https://…"}

POST /api/sound

音声データ URI を Redis に保存（TTL 1年）。22文字の短縮 ID を返却。最大 700KB。

GET /api/sound?id=xxx

短縮 ID から音声バイトをストリーミング。Immutable キャッシュヘッダー付き。

// api/_lib.js — 共通ユーティリティ
redis()    // Upstash Redis クライアント
token()    // Twitch app access token (client credentials)
id()       // nanoid 22文字 ID 生成
json(req)  // リクエストボディを JSON パース
base(req)  // レスポンスの CORS ヘッダー付きベース

Design Direction

デザイン方針・ユーザー要望メモ

全体トーン

「チープではなく洗練されたデザイン」。DUOLINGO のようなポップで UI/UX が磨かれたイメージ。

アラート吹き出し

長方形より両端が丸いカプセル型。グラスモーフィズム背景（ぼかし＋彩度）。フォント選択可。

アイコン

白いラインアイコン（Lucide 風）。塗りつぶしではなくストローク。CSS mask-image で着色。

ギフト演出

他より豪華に。グラデーションの縁。マーカーアニメ（shake・milestone）でドラマティックに。

エディタ

シンプルで使いやすく。セクションは折りたためるように。スクロールジャンプバグは修正済み。

注意点

「配信の空気をひとつ上の質感へ」のキャッチコピーは不要。ブランド名は SPARKLECHAT のみ。

エディタの主要バグ（修正済み）： トグル・セグメントコントロールをクリックすると画面が一番下に飛ぶバグ → .toggle{position:relative} と .segmented label{position:relative} を追加して修正。 hidden input の position:absolute がページ底部にアンカースクロールを引き起こしていた。
